# HDVIA Mobile Native Foundation

This release defines the mobile contract without pretending the native binaries
already exist. iOS/Android clients consume the same `/api/v1/openapi/*` contracts,
identity/session rules and journey/copilot/agent schemas.

The native app is deliberately downstream of the stable API contract.
